# 05_参数组合表（v2）

## 1. 用途

本文件把参考图分析结果转化为用户可确认的参数组合卡。

**v2 核心变化：**  
原版选项用气质词（"强机械感""硬朗感"），这类词会把图像模型带歪——它会套用训练数据里最接近的既有模板，而不是执行你的造型意图。  
v2 把所有选项改为**造型几何语言**，确保用户的选择能被正确翻译成出图指令。

---

## 2. 组合项来源

用户可见的参数组合项，只能来自：

1. `03_70维参数总表.md` I 组母体分析结果（优先）
2. `03_70维参数总表.md` 其他组内部分析结果
3. `04_图像分析输出模板.md` 的差异映射
4. `06_关键决策项筛选规则.md` 最终筛出的 3–6 项

**母体冲突项若存在，必须排在第一位，不得被其他项挤掉。**

---

## 3. 组合表输出原则

### 原则 A：只给少量高影响项
默认每轮展示 3–6 项，禁止摊开全量维度表。

### 原则 B：选项必须用几何语言而非气质词

| 禁止用的选项写法 | 应改成的写法 |
|---|---|
| 强机械感 / 弱机械感 | 主体表面切线数量：0条 / 2条 / 4条以上 |
| 强结构感 / 弱结构感 | 分件边界清晰度：隐藏 / 轻微可见 / 明显外露 |
| 超跑感强 / 超跑感弱 | 横向张力强度：无外扩 / 轻微外扩（+5%）/ 明显外扩（+10%以上）|
| 一体化 / 分离感 | 体块过渡方式：连续曲面 / 有台阶但无独立件 / 各体块独立 |
| 工具感 / 家居感 | 表面光泽：哑光无反光 / 半哑光 / 半光有少量反光 |

### 原则 C：母体项排第一
若存在母体选择，必须是第一个决策项，不得放在 CMF 之后。

### 原则 D：系统必须先筛选
用户看到的组合表是系统筛过的结果，不是原始差异全集。

---

## 4. 选项类型定义

每个关键决策项的选项，默认从以下类型构成：

- **偏 A**：主要继承参考图 A 的几何语法
- **偏 B**：主要继承参考图 B 的几何语法
- **融合**：在 A/B 之间取中，附带具体几何说明
- **新定义**：不直接继承 A/B，由系统按目标补出

---

## 5. 参数组合卡标准模板

```
决策项名称：
层级：母体级 / 特征级 / CMF级
为什么重要：
A方向（几何描述）：
B方向（几何描述）：
可选项：
  □ 选项1（几何描述）
  □ 选项2（几何描述）
  □ 选项3（几何描述，如有）
系统默认建议：
选错的主要风险：
```

## 6. 推荐输出格式示例

### 决策项 0：主母体选择（母体级，必须第一个决策）
- 重要原因：母体决定整体几何骨架，特征件必须附着在母体上，母体选错则后续一切无效
- A 方向：横向宽体扁平（高宽比 0.4:1，横向张力主导）
- B 方向：竖向圆台（高宽比 1.3:1，纵向收束）
- 可选：
  - 以 B 为主母体（竖向圆台），从 A 提取局部横向语法元素 ← 推荐
  - 以 A 为主母体（横向宽体），整体重构
  - 新定义：介于两者之间的均衡体（高宽比约 1:1）
- 默认建议：以 B 为主母体
- 风险：若两个母体混合而不选主，结果必然是外挂拼贴感

---

### 决策项 1：高宽比与横向张力（母体级）
- 重要原因：决定整体是横向展开还是纵向收束，影响"是否有跑车张力感"
- A 方向：横向张力强，高宽比约 0.4:1
- B 方向：纵向为主，高宽比约 1.3:1
- 可选：
  - 保持 B 的比例（高宽比 1.2–1.3:1），不引入横向张力
  - 在 B 的基础上轻微外扩：高度 35% 处左右各外扩 5–8%，高宽比调整至约 1.1:1 ← 推荐
  - 明显横向化：高宽比压缩至 0.9–1:1，横向感主导
- 默认建议：轻微外扩
- 风险：若选明显横向化，整体会偏离灯具形态，母体逻辑崩塌

---

### 决策项 2：体块过渡方式（母体级）
- 重要原因：决定产品看起来是"一件完整的东西"还是"几个零件拼在一起"
- A 方向：多体块拼接，过渡处有明显断裂
- B 方向：连续曲面，过渡自然
- 可选：
  - 连续过渡：顶部、主体、底座为一体连续曲面，无独立分件感
  - 轻微分层：顶部与主体之间有 1 条约 2mm 的切线，底座有 1 条切线，共 2 条，其余连续 ← 推荐
  - 明显分层：顶部、主体、底座各为独立件，有明显台阶
- 默认建议：轻微分层（2 条切线）
- 风险：若选明显分层，顶部容易变成"突兀黑盖"效果

---

### 决策项 3：特征件显性程度（特征级）
- 重要原因：决定记忆点是融入主体还是独立于主体之外
- A 方向：特征件非常强，独立于主体之外
- B 方向：几乎无特征件，发光件隐性
- 可选：
  - 隐性：特征件完全嵌入主体，与主体面齐平，无突出
  - 半显性：特征件嵌入主体，略凹于表面，宽约 3–4mm ← 推荐
  - 显性：特征件略突出于主体轮廓，宽约 6–8mm
- 默认建议：半显性嵌入
- 风险：若选显性，容易脱离主体形成外挂感

---

### 决策项 4：商品化程度（整体级）
- 重要原因：决定结果更像"能卖的成品"还是"概念展示模型"
- A 方向：概念感强，可信度低
- B 方向：成熟商品感，工艺可信
- 可选：
  - 高商品化：所有分件逻辑清晰，工艺表达真实，无假结构
  - 中商品化：主要区域工艺可信，允许少量装饰性设计表达 ← 推荐
  - 概念化：允许不可信工艺，以视觉效果为优先
- 默认建议：中商品化
- 风险：若选概念化，落地倾向丧失，买家看不出这是真实产品

---

## 7. 缩项规则

候选决策项超过 6 个时，按以下顺序裁剪：

**第一优先保留（母体级）：**
- 主母体选择
- 高宽比与横向张力
- 体块过渡方式

**第二优先保留（特征级）：**
- 特征件显性程度
- 发光件几何位置
- 商品化程度

**优先删除：**
- 与更高层项重复的项
- 图像判断置信度低的项
- 可自动补全的次级 CMF 项

---

## 8. 自动建议机制

每个决策项都应给出系统建议，必须满足：

1. 有几何依据，不是主观偏好
2. 简短
3. 说明主要风险

禁止：
- 无依据推荐
- 全部推荐"融合"而不说明融合的几何含义
- "随便都行"的模糊建议

---

## 9. 用户不想细选时的快速模式

若用户不想逐项选择，系统走快速模式：

**快速模式默认参数（几何语言）：**
- 主母体：以 B 图为主，A 图提取局部语法
- 高宽比：1.1–1.2:1，轻微横向外扩
- 体块过渡：轻微分层（2 条切线，无独立件）
- 特征件：1 个半显性嵌入特征件
- 商品化程度：中商品化

系统必须明确告知用户：**已按默认高质量模式自动补全，主要参数如上。**
