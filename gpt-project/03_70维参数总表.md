# 03_70维参数总表（v2）

## 1. 使用说明

本文件用于系统内部完成三件事：

1. 对两张参考图做统一口径分析
2. 建立 A/B 差异映射
3. 为关键决策项筛选提供数据基础

### 对外规则
- 本文件默认**只内部使用**
- 不得全量展示给用户
- 对外必须先经过《06_关键决策项筛选规则》

### v2 核心变化
原版偏"特征目录"——只记录有没有某个特征件。  
v2 增加 **I 组：母体造型语法**，优先级高于其他所有组。  
分析顺序必须从 I 组开始，而不是从 A 组开始。

## 2. 参数分析通用格式

每一维参数分析时，系统必须记录：

| 字段 | 说明 |
|------|------|
| 参数编号 | |
| 参数名称 | |
| 所属类别 | |
| A 图判断值 | |

| 差异等级 | 高 / 中 / 低 / 不可判断 |
| 判断置信度 | 高 / 中 / 低 / 不可判断 |
| 是否可自动补全 | 是 / 否 |
| 是否进入关键决策候选池 | 是 / 否 |
| 备注 | |

### 差异等级定义
- **高差异**：两图明显不同，且会显著影响结果
- **中差异**：两图不同，但影响有限或可被其他项覆盖
- **低差异**：两图基本一致或差异极小
- **不可判断**：图像信息不足，不得脑补

### 自动补全许可条件（同时满足）
1. 差异非高差异
2. 对最终外观影响不大
3. 系统已有稳妥默认值
4. 不会显著改变设计方向

## 3. 分析执行顺序

**必须按以下顺序执行，不得跳组：**

```
I 组（母体造型语法）→ B 组（轮廓与体块）→ C 组（比例与层级）
→ D 组（结构暗示）→ E 组（功能组织）→ F 组（细节特征）
→ G 组（CMF）→ H 组（整体气质）→ A 组（产品定位）
```

**I 组是最高优先级。** 若 I 组存在母体冲突，必须先处理，再继续后续分析。

## 4. I 组｜母体造型语法（0–1 至 0–8）

> **什么是母体？**  
> 母体是产品整体的几何骨架——它决定第一眼看到的是"圆台""扁盘""方柱"还是"横向宽体"。  
> 特征件是附着在母体上的，不是母体本身。  
> 母体判断错了，特征件再对也没用。

### 0–1. 母体几何类型
判断口径：剥掉所有特征件后，主体是什么基础几何形态  
常见值：竖向圆台 / 竖向圆柱 / 横向扁体 / 方柱体 / 胶囊体 / 异形体

### 0–2. 母体高宽比
判断口径：整体高度与最大宽度之比，影响横向/纵向张力  
记录格式：数值区间，如 0.8:1（矮胖）/ 1:1（均衡）/ 1.5:1（偏高）/ 2:1 以上（细高）  
判断方向：偏横向张力 / 偏纵向张力 / 均衡

### 0–3. 母体横向张力
判断口径：整体视觉重心是否横向展开，而非竖向收束  
常见值：强横向张力 / 中等 / 弱（纵向主导）

### 0–4. 母体视觉压缩感
判断口径：整体看起来是"被横向压扁"还是"竖向拉伸"  
常见值：明显压缩 / 轻微压缩 / 无压缩感 / 拉伸感

### 0–5. 体块过渡方式
判断口径：各主要体块之间如何衔接  
常见值：  
- 一体连续过渡（无明显分界）  
- 软过渡（有渐变但不断裂）  
- 硬分层（有明显台阶或切线）  
- 拼接叠加（各体块独立感强）

### 0–6. 主视觉重心位置
判断口径：第一眼视线最自然停留的区域  
常见值：顶部 / 上 1/3 / 中部 / 下 1/3 / 底部 / 分散

### 0–7. 特征件允许位置
判断口径：基于母体，特征件放在哪里才不破坏整体性  
常见值：  
- 仅允许腰线区域  
- 仅允许顶部过渡区  
- 仅允许底座区  
- 允许正面主视觉面  
- 不允许顶部独立存在  
- 不允许环绕分布（会破坏方向感）

### 0–8. 母体与参考图母体是否存在根本冲突
判断口径：A 图母体与 B 图母体是否在根本几何类型上矛盾  
常见值：  
- 无冲突（同类母体）  
- 轻度冲突（可融合）  
- **高度冲突（必须先选主母体，不可混合）**

> **高度冲突典型案例：**  
> - A 图：横向宽体超跑尾部（横向张力强）  
> - B 图：竖向圆台灯具（纵向收束）  
> → 这两个母体不可直接混合。必须先选定一个作为主母体，另一个只能提取局部语法元素。  
> 若跳过这一步直接融合，结果必然是外挂拼贴，而不是造型融合。

## 13. 关键决策候选池接口

进入候选池的条件（满足 3 条以上）：

1. 差异等级为高或中高
2. 对最终外观影响明显
3. 不能安全自动补全
4. 与目标产品强相关
5. 与可落地倾向或设计强度相关

**特别规则：I 组中存在高度母体冲突时，母体选择项必须强制进入候选池第一位，优先于所有其他项。**

进入候选池后，再由《06_关键决策项筛选规则》压缩为 3–6 个用户可见项。
