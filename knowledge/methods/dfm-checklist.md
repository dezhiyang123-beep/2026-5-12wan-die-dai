# DFM检查清单 v2.0

> 调用时机：engineering-integrator在G4执行轻量DFM评分；G6执行完整风险清单。

## G4轻量DFM：6轴0/1/2评分（补丁修正7）

### 评分规则

| 轴 | 0分（无风险） | 1分（有风险可控） | 2分（高风险） |
|---|---|---|---|
| **assembly** | 标准装配顺序 | 需特殊工装 | 严重装配顺序约束 |
| **thermal** | 自然散热可行 | 需结构散热路径 | 散热路径不明 |
| **cable_routing** | 走线路径清晰 | 需弯折穿孔 | 走线冲突 |
| **ingress_protection** | 不需要防水 | 需密封且可实现 | 防水与结构矛盾 |
| **tooling_complexity** | 标准模具无侧抽 | 需侧抽滑块 | 特殊工艺（压铸/精铸） |
| **serviceability** | 免工具维护 | 需工具但可操作 | 需拆解主结构 |

### 总分判定

- **0-3分：绿（通过）** — 继续G5
- **4-7分：黄（标注风险）** — 继续G5，在11_pitch_deck.yaml中标注
- **8-12分：红（hard stop）** — 不得进G5，必须回G3修改母题

### 输出格式

```yaml
dfm_quick_check:
  assembly: 0      # 0/1/2
  thermal: 1
  cable_routing: 0
  ingress_protection: 1
  tooling_complexity: 2
  serviceability: 0
  total_score: 4   # 6轴之和
  dfm_verdict: yellow
  red_items: []    # 红灯时填写导致红灯的轴
```

## G6完整DFM：6类风险覆盖

### 1. 结构风险
- 核心结构能否用现有模具/工艺实现
- 壁厚均匀性（注塑：最小1.2mm，最大差≤2:1）
- 分件线位置合理（不在主要可见面）
- 装配方向单一（避免多方向装配）
- 活动件/铰链耐久性目标次数

### 2. 电气风险
- 电池类型和容量对应认证（UN38.3/UL2743）
- PCB保护电路完整
- 充电方式（Type-C）的防水处理
- FCC/CE电磁兼容处理

### 3. 可靠性风险
- 跌落测试要求（客户档案或MIL-STD-810G）
- 防水等级实现方式（IP54/IP65/IP68）
- 按键/接口耐久次数（通常≥10000次）
- 电池循环寿命目标（通常≥500次）

### 4. 人因风险
- 握持/操作尺寸在Dreyfuss标准包络内
- 关键操作可单手完成
- 防误触设计
- 视觉反馈是否足够

### 5. 成本风险
- BOM估算在目标价格带的30-40%以内
- 高成本零件的降级选项
- 模具费与量产数量摊销合理性

### 6. 法规风险
- 必须认证清单与当前设计不冲突
- California Prop 65包装合规
- RoHS/REACH合规

## 风险等级定义

- **H（高）**：不解决则产品无法量产或无法通过认证
- **M（中）**：影响成本或交期，建议解决
- **L（低）**：优化项，不影响基本交付
