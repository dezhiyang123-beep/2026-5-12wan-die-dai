# M2 快速模式 — 时间预算与规则

## 适用场景

- 已知客户+已有清晰方向指向
- 时间紧迫的快速验证
- 品类已熟悉，情报需求较低

## 硬规定

- **不能跳过G1**（商务前提必须验证）
- 方向≤2个
- 母题8张（直接进G4，不需要筛选）
- 客户版5套

## 时间预算

| 阶段 | 预算 |
|------|------|
| G0+G1 | 30min |
| G2 | 30min |
| G3（方向+母题） | 1.5h |
| G4+出图 | 1h |
| G5 | 1h |
| G6 | 1.5h |
| **总计** | **约6h** |

## 超时规则

同M1，任一关卡超出预算50%输出超时提示。

## 漏斗保护规则（补丁额外5）

如果G4后废弃包（DFM红灯）≥3个，导致可用包<6个：
- **自动回G3补出2张母题**
- 输出提示：`快速模式漏斗保护：可用包不足（当前[N]包），回G3补出2张母题`
- 补出后重新执行G4

## M2与M1的差异

| 维度 | M1标准 | M2快速 |
|------|--------|--------|
| G0+G1时间 | 1h | 30min |
| 方向数量 | 2-3个 | ≤2个 |
| 母题数量 | 12张→用户筛8张 | 直接出8张 |
| G4渲染包 | 8包 | 8包 |
| G5客户版 | 5套 | 5套 |
