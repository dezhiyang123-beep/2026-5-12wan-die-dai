# M3 逆向成本模式 — 时间预算与规则

## 适用场景

- BOM上限已锁定（如客户给了目标采购价）
- 需要先确认成本可行性再做造型
- 价格敏感型品类

## 核心逻辑

先锁BOM上限，反推可以做什么造型方案。
G3方向研判时额外增加BOM反推步骤。

## 时间预算

| 阶段 | 预算 |
|------|------|
| G0+G1 | 1h |
| G2 | 1h |
| G3方向（含BOM反推） | 1h（比M1多30min） |
| G3母题 | 1.5h |
| G4+DFM | 1.5h |
| G5 | 1h |
| G6轻版 | 1h |
| G6深版+PPT | 2h |
| **总计** | **约10.5h** |

## BOM反推步骤（G3额外）

在G3方向研判完成后，对每个方向执行BOM反推：
1. 从 form_handoff_brief.cost_ceiling_per_unit 读取BOM上限
2. 逆推主要零件的成本分配（外壳/PCB/驱动/光学/包装各占比）
3. 检查每个方向的 cost_tier 是否在BOM上限内
4. 超出→直接标注该方向为"超预算方向"，不进G3母题

## 方向和母题数量

- 方向：2-3个（但超预算方向会被过滤）
- 母题：12张→用户筛8张
- 客户版：5套

## M3与M1的差异

| 维度 | M1标准 | M3逆向 |
|------|--------|--------|
| G3方向 | 研判→form_handoff_brief | 研判→BOM反推→过滤→form_handoff_brief |
| 额外时间 | - | G3增加30min |
| cost_ceiling权重 | 参考 | 硬约束（超出直接过滤） |
