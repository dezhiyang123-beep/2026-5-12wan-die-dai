# M1 标准模式 — 时间预算与规则

## 适用场景

- 陌生客户或陌生品类
- 主动开发（非客户指定需求）
- 需要完整情报支撑的决策

## 时间预算（补丁修正8）

| 阶段 | 预算 |
|------|------|
| G0+G1（立项+商务验证） | 1h |
| G2（用户动作建模） | 1h |
| G3方向研判 | 30min |
| G3母题生成（12张） | 1.5h |
| G4渲染定义包（8包）+DFM | 1.5h |
| G5图像回审+收敛 | 1h |
| G6轻版（5套） | 1h |
| G6深版（Top 2-3）+PPT | 2h |
| **总计** | **约10h** |

## 超时规则

任一关卡超出预算50%，输出：
`当前关卡超时，建议收敛到最低可交付标准继续推进`

## 漏斗规则

G3出12张母题 → 用户筛到8张 → G4出8个渲染包 → G5收敛5套客户版 → G6轻版5套+深版Top 2-3

## 方向和母题数量

- 方向：2-3个
- 母题：12张（用户筛到8张进G4）
- 客户版：5套
