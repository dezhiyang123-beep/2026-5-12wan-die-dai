# Step 00：Brief 完整性检查

## 定位
这是整个流程的入口闸门。垃圾进垃圾出——brief 不完整就开跑，后面全是浪费。
本步骤在用户输入任何内容后立刻执行，判断信息是否足够启动流程。

## 执行

### Brief内部矛盾检查

必填字段齐全后，检查需求间是否存在矛盾：
- "轻量" vs "奢华厚重感"
- "低成本" vs "高端材质"  
- "极简" vs "功能外显"
- 其他语义冲突的需求组合

发现矛盾 → 列出矛盾点，问用户优先哪个。不能带着矛盾进入Step 01。

### 必填字段清单

以下字段必须明确才能启动流程：

| 字段 | 说明 | 缺失时的处理 |
|------|------|-------------|
| 品类 | 产品类型（如"LED Grow Light"） | 停机，必须问 |
| 目标市场 | 销售地区（如"北美"） | 停机，必须问 |
| 价格带 | 目标零售价或FOB区间 | 停机，必须问 |
| 项目意图 | 新品探索/现有迭代/降本替代/旗舰概念/渠道定制 | 停机，必须问 |

### 强烈建议字段

以下字段没有不阻断，但系统会标注信息缺失风险：

| 字段 | 说明 | 缺失时的处理 |
|------|------|-------------|
| 客户名 | 品牌商名称 | 进入M1a品类优先模式，Step 04再匹配 |
| 销售渠道 | 电商/经销商/工程项目/零售 | 标注[UNKNOWN]，Step 02补充 |
| 尺寸限制 | 物理约束（如"宽度≤300mm"） | 标注[UNKNOWN]，Step 08前必须明确 |
| 成本目标 | BOM上限或目标毛利率 | 标注[UNKNOWN]，Step 04 F10补充 |
| 竞品 | 主要竞争对手 | 标注[UNKNOWN]，Step 02补充 |
| 禁忌风格 | 客户绝对不接受的设计方向 | 标注[UNKNOWN]，Step 04品牌红线补充 |
| 产量预期 | 年产量级别（千/万/十万） | 标注[UNKNOWN]，影响工艺选择 |
| 交付时间 | 期望什么时候拿到方案 | 影响流程模式选择 |

### 执行逻辑

```
1. 扫描用户输入，提取已提供的字段
2. 检查4个必填字段是否齐全（品类、目标市场、价格带、项目意图）
   - 缺失 → 列出缺什么，问用户补充，不往下跑
   - 齐全 → 继续
3. 检查建议字段的缺失情况
   - 列出缺失字段 + 对后续步骤的影响
   - 不阻断，标注[UNKNOWN]后继续
4. 所有项目走完整11步。不判断模式，不跳步。
5. 加载客户记忆（如有）：
   - 检查 .claude/clients/{客户名}/ 目录是否存在，加载 brand_grammar.yaml 和 preferences.yaml
   - 如有 → 标注"已加载历史客户记忆"，后续步骤自动引用
   - 如无 → 标注"新客户，将从零建立品牌认知"
6. 加载3层记忆：
   a. 用户层：读取 `.claude/memory/user/preferences.yaml`，注入用户工作习惯和通用偏好
   b. 客户层（如有客户名）：
      - 读取 `.claude/clients/{客户名}/brand_grammar.yaml`（品牌语法，取最新版本块）
      - 读取 `.claude/clients/{客户名}/preferences.yaml`（客户偏好，取最新版本块）
      - 读取 `.claude/clients/{客户名}/live_memory.yaml`（对话中即时捕获的记忆信号）
      - 读取 `.claude/clients/{客户名}/project_history.yaml`（历史项目经验）
   c. 跨客户扫描：扫描所有客户的project_history.yaml中的failures条目，检查是否有rule_scope=category或universal的规则已达到变更阈值（品类≥2次、通用≥3客户）。达到阈值的规则自动提示用户确认。
   d. 将所有加载的记忆注入后续步骤上下文。
```

## 输出

```yaml
brief_status: "COMPLETE" / "INCOMPLETE"
missing_required: []          # 缺失的必填字段
missing_recommended: []       # 缺失的建议字段 + 影响说明
run_mode: "standard（所有项目统一）"
client_memory_loaded: true/false
warnings: []                  # 如"成本目标未知，Step 07可能无法做硬杀筛选"
```

如果 COMPLETE → 自动进入 Step 01（品类扫描）
如果 INCOMPLETE → 列出问题，等用户补充

### 产出完整性自检
- [ ] 4个必填项已确认齐全
- [ ] Brief内部矛盾已检查（无矛盾或矛盾已解决）
- [ ] 建议字段缺失已标注[UNKNOWN]
- [ ] 3层记忆已加载（用户层+客户层+跨客户扫描）
- [ ] 运行模式已确认（standard）
