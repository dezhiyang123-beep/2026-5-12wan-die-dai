# Step 08：渲染控制与迭代

## 输入
- Step 07 的5个设计深化定义（含渲染锚定准备：参考图+差异描述+禁止项）
- Step 06 每个概念的 render_anchor（素材库参考图）

## 前置检查

### 检查1：第一视觉特征确认（必须通过才能继续）
对每个要出图的方案，回答三个问题：
1. **10米外第一眼看到什么？**（一句话，不超过14字）
2. **这个特征为什么属于这个客户而不是别家？**（必须和品牌DNA绿灯表对得上）
3. **去掉logo后，客户能否区分它和竞品？**（如果不能，主特征不够强）
说不清楚或触犯红线 → 停机，回Step 07补完。

### 检查2：品牌检查（Always-on）
对照品牌DNA红线表：
- CMF方向是否在绿灯表范围内？
- 形态语言是否触犯任何红线？
不通过 → 停机，回Step 07修正。

### 检查3：品牌红线传递检查（四问）
1. 违反红线了吗？
2. 为创新扩大了创新半径吗？
3. 出现品牌从没用过的视觉语言了吗？
4. 像另一个品牌了吗？
不通过 → 停机，回Step 07修正。

## 框架调用
通过前置检查后，调用：
1. F16 出图锁定清单（步骤级必备 — Step 08执行时必跑）

## 执行

### 第零步：3张渲染参考图准备（V4.3升级）

每个概念的渲染需要**3张参考图**，按优先级排列：

```yaml
render_reference_pack:
  1_category_skeleton_ref:
    priority: "highest — 控制产品不跑品类"
    source: "品类标杆库中的同品类产品"
    purpose: "锁定产品基本结构、比例、器官位置"
    example: "DeWalt DCD999电钻 → 控制电钻的基本骨架"
    
  2_brand_style_ref:
    priority: "high — 控制品牌气质"
    source: "品牌语法库中的同品牌产品"
    purpose: "锁定CMF、分件语言、包胶方式、品牌色分区"
    example: "DeWalt其他系列产品 → 控制黄黑分区和粗犷工业感"
    
  3_detail_ref:
    priority: "medium — 控制局部Hero Feature"
    source: "设计手法库中的参照"
    purpose: "锁定某个具体细节的形态"
    example: "某运动装备的握把纹理 → 控制防滑区设计"
```

**3张参考图来源约束**：
- 品类骨架参考：从01_品类标杆库选，优先客户品牌自身或同档竞品
- 品牌风格参考：从02_品牌语法库选客户品牌的产品图
- 局部细节参考：从03_设计手法库或跨品类选，不能和前两张来自同一品牌
- 3张参考图来自≥2个不同品牌。不允许3张全来自同一品牌。

**图片准备规则**：
- 3张图全部复制到 `~/Desktop/渲染参考图/C-{XX}_骨架参考.jpg` / `_品牌参考.jpg` / `_细节参考.jpg`
- 如果某张缺失（如品牌语法库还没建）→ 先问用户找一张 → 用户不提供则该层用文字描述替代
- **知识参照卡不能做任何一张参考图**（没有实物图=不可靠）

**渲染AI不能自由理解"DeWalt风格"** — 必须通过品牌参考图上的可见元素控制：黄色区域在哪、黑色橡胶怎么包、机身体量怎么压、散热口什么形态、分件线怎么走。

**没有图的灵感，不能主导最终视觉方案。**

### 第一步：生成渲染提示词

为每个概念生成 1 份主视角提示词。按两种模式选择：

**模式A：参考图+差异描述（首选，80%的情况用这个）**

适用条件：素材库中有匹配的参考图

```
=== 渲染参考图 ===
[附上参考图]

=== KEEP（必须原样保留）===
1. [F16锁定项]
2. [如"整体扁平长条的比例关系"]
3. [如"正面中央的线性出光开口"]

=== CHANGE（和参考图相比的修改）===
1. [修改项 → 改成什么]
2. [修改项 → 改成什么]

=== MATERIAL ===
- 主体：[材料+表面处理+触感]
- 特征面：[材料+效果]
- 细节件：[材料+处理]

=== CAMERA ===
- 角度：[如"3/4俯视，约45度"]
- 背景：[白色/浅灰 或 场景描述]
- 光线：[主光+补光]

=== QUALITY ===
- 风格：[如"professional product photography, studio lighting, commercial quality"]

=== REFERENCE IMAGE INSTRUCTIONS（参考图权重说明，V4.3.1新增）===
Use Reference Image 1 (category skeleton) ONLY for overall product structure and proportions.
Use Reference Image 2 (brand style) ONLY for brand CMF, parting lines, and surface treatment.
Use Reference Image 3 (detail) ONLY for the specific local feature described in CHANGE section.
Do NOT copy the full shape of Reference Image 3 — only borrow the specified detail.

=== MUST NOT（绝对禁止）===
1. [品牌红线禁止项]
2. [上一轮漂移项]
3. [如"No decorative texture"]
4. [如"No visible screws"]
5. [如"No corner radius > 2mm"]
```

**模式B：纯文字创意总监brief（没有合适参考图时用）**

```
[产品类型] professional product photography.

Product: [3句话。第1句=整体形态+比例。第2句=Hero Feature占50%篇幅。第3句=材质感觉]

Scale: [参照物尺寸感]

Material & Surface: [具体材料+表面处理+触感]

Composition: [角度, 焦段, 景深]

Lighting: [主光+补光+环境光]

Background: clean white/light gray studio backdrop

Style: professional product photography, studio lighting, commercial quality

=== Must preserve ===
1. [Hero Feature的几何描述]
2. [体块关系的比例]
3. [F16锁定项]

=== Must NOT appear ===
1. [品牌红线禁止项]
2. [至少4条几何禁止约束]
```

**模式B升级策略**（无合适参考图时）：
1. 先用模式B出一张粗图
2. 从粗图结果中选最接近概念定义的一张
3. 把这张粗图作为参考图，切换到模式A继续迭代
4. 模式B的最大独立迭代次数为2次（不是3次），超过必须切模式A

### 第二步：准备出图材料（系统自动执行）

系统为用户准备可直接使用的出图包：

1. **复制参考图到桌面**（模式A时）：
   - 将素材库中的参考图复制到 `~/Desktop/渲染参考图/`
   - 命名为 `C-{XX}_骨架参考.jpg` / `C-{XX}_品牌参考.jpg` / `C-{XX}_细节参考.jpg`（按概念编号+参考类型命名）
   - 每个新项目开始时先清空该文件夹，避免和上个项目混淆

2. **输出提示词**：在对话中直接给出完整提示词文本

**用户操作**：
- 打开 `桌面/渲染参考图/` → 找到对应图片
- 打开 ChatGPT / Gemini / Nano Banana → 上传图片 → 粘贴提示词 → 发送
- 把出图结果反馈给系统（截图或描述）

### 第三步：看图→判断→迭代

用户反馈出图结果后，系统协助判断问题出在哪一层，并给出对应的修改方案：

**根因诊断（迭代前必须先做）**：
出图结果不满意时，先判断问题根因，再决定改什么：
| 根因层级 | 症状 | 处理 |
|----------|------|------|
| 提示词不精准 | 大方向对但细节偏差 | 修改提示词的CHANGE/MUST NOT |
| 参考图选错 | 整体风格/比例和概念不匹配 | 从素材库重新检索更匹配的参考图 |
| Step 07设计定义有矛盾 | 出图暴露了深化阶段未发现的几何冲突 | 回Step 07修正设计定义 |
| Step 03造型意图偏了 | 出图看起来和痛点回应无关 | 回Step 03重新翻译造型意图 |
| 品牌语法提取不准 | 出图像另一个品牌 | 回Step 03校准品牌语法 |

先做根因诊断，确定在哪一层，再按对应层级处理。不要所有问题都靠改提示词。

**第1层：造型方向不对**（最严重）
- 症状：整体轮廓/体块关系/主特征和概念定义明显不一致
- 原因：提示词描述不够精准，或参考图和概念差距太大
- 修改方案：
  - 更换参考图（从素材库重新检索更接近的）
  - 重写差异描述，用更精确的几何语言
  - 如果换图+重写还不行 → 回 Step 07 检查概念定义本身是否有问题

**第2层：细节不对，大方向对**
- 症状：轮廓对了，但某些局部元素多了/少了/位置不对
- 修改方案：
  - 把出错的细节加入"禁止项"
  - 把想要的细节加入"保留项"并描述更具体
  - 不要重写整个提示词，只改出问题的部分

**第3层：材质/CMF不对，造型对**
- 症状：形状对了，但颜色/材质/表面处理不对
- 修改方案：只改材质与表面部分，造型描述完全不动

**第4层：渲染风格不对**
- 症状：产品形态和材质都对，但整体风格不对（太CG/太卡通/太暗/太亮）
- 修改方案：只改 Style + Lighting 部分

**迭代规则**：
- 每次迭代只改一层问题，不要同时改造型+材质+风格
- 如果第1层问题迭代3次还没解决 → 停机，回Step 08重新审视概念定义
- 如果回Step 07后仍无法修正 → 该概念放弃，从Step 05的候选概念中替补一个重新走Step 07-08
- 用户满意后，输出该概念的场景图提示词（场景图对造型精度要求较低，通常1-2次就能出好）

### 第四步：逐个概念推进

5个概念逐个执行"出提示词→用户出图→看图→迭代"循环：
- 概念1完成（用户满意主视角+场景图）→ 概念2 → ... → 概念5
- 每个概念的迭代经验（哪些禁止项有效、哪些描述方式更精准）自动累积到后续概念的提示词中

### 场景图选景规则
场景图的场景选择必须匹配：
- **品类**：户外灯→建筑外立面/庭院/道路；室内灯→餐厅/客厅/办公室；电动工具→工地/车间/家装现场
- **客户品牌调性**：工业品牌→工地/商业建筑；消费品牌→家庭/生活场景；建筑品牌→高端住宅/酒店
- **目标用户**：承包商→施工现场；设计师→展厅/样板间；消费者→日常生活场景
- **光线**：匹配产品实际使用时间（户外灯→黄昏/夜晚；工作灯→室内昏暗环境）

### 关键规则
- 不写工程参数（不写"480W""1200mm"）
- 不写功能描述（不写"双通道可调光谱"）
- 只写视觉信息——AI看到提示词后脑子里应该能浮现出产品的样子
- 材质描述具体到可触摸的感觉（"冷感的拉丝铝"不是"铝合金材质"）
- 如果产品有发光部分，描述发光的颜色、亮度感、边界（渐变/锐利）

## 输出

每个概念最终输出：
```yaml
concept_id: "C-01"
render_mode: "A 或 B"
hero_shot_prompt: "最终通过的主视角提示词"
context_shot_prompt: "场景图提示词"
iteration_count: 3  # 迭代了几轮
drift_log: ["第1轮：AI自行添加了顶部装饰环，已加入禁止项", "第2轮：材质偏亮，改为matte"]
```

全部5个概念完成后，进入 Step 09 交付包装。

- [ ] 品牌红线四问已回答
