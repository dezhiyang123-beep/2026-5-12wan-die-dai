# Step 06：视觉总监审查

## 目标
在设计深化之前，对5个概念做视觉层面的终审。确保每个概念不只"合理"，而且"好看、有记忆点、像该品牌"。

**视觉总监有否决权。** 否决的概念回 Step 05 替换。

## 输入
- Step 05 确认的5个概念（含钩子卡+渲染锚定）
- Step 02 品类骨架
- Step 03 品牌语法

## 执行

### 审查1：品牌距离 + 创新距离双轴评分

每个概念打两个分：

```yaml
dual_score:
  brand_distance:    # 像不像该品牌
    1: "完全不像该品牌"
    2: "有品牌元素但气质偏离"
    3: "基本像该品牌"
    4: "像该品牌的新产品"
    5: "像该品牌下一代旗舰产品"
    
  novelty_distance:  # 比现有产品多走了几步
    1: "和现有产品几乎一样"
    2: "局部有新意"
    3: "明显有新设计方向"
    4: "显著创新，但仍在品牌内"
    5: "颠覆性创新"
```

**最优区间**：品牌距离 4 + 创新距离 3-4。

| 组合 | 判断 |
|------|------|
| 品牌5 + 创新1 | 太保守，不够新 |
| 品牌2 + 创新5 | 跑偏了，不像品牌 |
| 品牌4 + 创新4 | **最优，适合B2B提案** |
| 品牌3 + 创新3 | 及格，但不够出彩 |

**品牌距离 < 3 → 直接淘汰。**

### 审查2：视觉协调性

对每个概念检查：

| 检查项 | 问题 |
|--------|------|
| 主次关系 | Hero Feature是否是视觉第一主角？有没有其他元素抢戏？ |
| 细节服从整体 | 借来的跨品类细节融入了吗？还是像贴上去的？ |
| 比例合理 | 像不像该品类的产品？会不会头重脚轻/比例怪异？ |
| 设计动词统一 | 所有造型决策是否服务同一个动词？有没有互相矛盾的元素？ |
| 拼接感 | 看起来是一个完整产品，还是几个零件拼起来的？ |

任一项严重不通过 → 标记 `visual_fail`，回 Step 05 替换或修正。

### 审查3：标杆对比（V4.3.1新增，视觉总监不能自说自话）

视觉总监必须把每个概念和3个标杆对比：

```yaml
benchmark_comparison:
  vs_brand_current:
    compare: "同品牌现有产品中最接近的一款"
    question: "我们的概念比它多了什么？少了什么？"
    
  vs_category_best:
    compare: "同品类设计水平最高的产品"
    question: "我们的概念比它差在哪？有没有某一点超过它？"
    
  vs_competitor_flagship:
    compare: "主要竞品的旗舰产品"
    question: "我们的概念和它放一起，客户更容易记住谁？"
```

**没有对比，评分无效。** 所有"好不好看"的判断必须基于对比，不能凭空自评。

**标杆对比必须有具体内容**：
每个对比不能只写"PASS"或打分。必须写出：
- vs品牌现有：我们的概念比它具体多了什么造型元素？少了什么？
- vs品类最佳：我们在哪个维度接近/超过它？在哪个维度明显不如？
- vs竞品旗舰：放在一起，客户视线会先落在谁身上？为什么？

只有分数没有对比内容的审查无效。

### 审查4：记忆点验证

```
去掉所有文字说明，只看这个概念的造型描述。

1. 3秒后你还能记住什么？（如果记不住任何特征 → 没有记忆点 → FAIL）
2. 这个记忆点和痛点回应一致吗？（记住了"好看"但记不住"轻" → 偏离B=60%）
3. 这个记忆点是否只属于该品牌？（其他品牌也可以做 → 差异化不够）
```

### 审查5：Hero Claim 验证

每个概念必须能回答：

```yaml
hero_claim:
  第一记忆点是什么: ""
  客户3秒后还能记住什么: ""
  销售能用一句话怎么卖: ""
  去掉这个特征方案是否立刻变普通: true/false  # false → 这个方案没有灵魂
```

`去掉特征后没有损失` → 该概念缺少灵魂，标记 `no_soul`，不能做冠军款。

### 品牌红线传递检查（每个概念必答）
1. 这个设计有没有违反品牌红线？
2. 有没有为了创新而扩大客户创新半径？
3. 有没有出现客户品牌从未使用过的视觉语言？
4. 有没有让产品看起来像另一个品牌？

任一项回答"是" → 标记问题并决定是修正还是淘汰。

## 输出

5个概念的视觉审查结果：

```yaml
visual_review:
  - concept_id: "C-01"
    brand_distance: 4
    novelty_distance: 3
    visual_harmony: "PASS"
    memory_point: "深V散热峡谷"
    hero_claim_valid: true
    verdict: "PASS"
    
  - concept_id: "C-03"
    brand_distance: 2
    novelty_distance: 4
    visual_harmony: "FAIL - 跨品类细节拼接感明显"
    memory_point: "有，但不像该品牌"
    hero_claim_valid: true
    verdict: "FAIL - 品牌距离不够，回Step 05修正"
```

通过审查的概念进入 Step 07 设计深化。未通过的回 Step 05 替换。

### 失败回退路径

**【R9】回退规则加品类感知豁免 + 回退计数器**

**回退计数器**：本次执行中回退次数记录为 N（初始=0）。N≥2 → 停止循环回退，升级为"用户决策点"，向用户说明根本原因和可选路径，不再自动回退。

**品类感知豁免规则（R9）**：
以下情况的方案不触发"体量过于单一"类回退：
- 品类身份锚点为矩形盒体的品类（车载冰箱/储物箱/配电箱/电池组/充电器），矩形体量不是设计问题而是品类必要条件
- 方案主视觉特征在侧面/顶面/分件处，正面矩形不等于无记忆点
- 品类默认无轮廓记忆点（如方形器具类）→ 记忆点检查降级到"细节/CMF/比例"层而非"整体轮廓"层

**常规失败回退**：
- **全部5方案品牌距离<3**：N+=1；从Step 05第1轮存活但未入选的候选概念中选总分最高者替补。如候选也不足，回到Step 03重新调整品牌创新半径。
- **被淘汰概念即时入反例库**：品牌距离<3被淘汰的概念，当场写入反例库，记录"品牌距离不足"的具体原因。
- **视觉评分全部INVALID（无法评分）**：检查Step 05低保真草图锁定是否完成。如Step 05 visual_object_valid均为false → 不回退Step 06，直接回Step 05补完视觉描述后重新提交。
