# 视觉素材库规范

## 定位
视觉素材库是系统的"眼睛"——让AI能基于真实的优秀设计做参照，而非凭空编造造型。
素材库为 Step 04（灵感检索）和 Step 05（概念生成）提供视觉锚点，为 Step 08（效果图提示词）提供渲染参考图。

## 素材库路径
用户桌面：`~/Desktop/设计素材库/`（爬取和存储）
系统索引：`.claude/knowledge/素材索引/`（DNA卡存放处，按品类分文件夹）

### 品牌文件夹标准化规则（V4.3.1新增）

品牌语法提取的准确度直接取决于品牌素材的组织方式。乱放一个文件夹 = 语法被平均化。

**必须分层存放**：
- `current_line/`：当前在售的代表产品（品牌语法的主要数据源）
- `premium_series/`：高端系列（提取品牌能做到的上限）
- `entry_series/`：入门系列（提取品牌的下限，避免低端产品拉低语法）
- `detail_views/`：多角度图（侧面/背面/底部，比例码和结构码必须有多角度才准）
- `competitor_boundary/`：主要竞品图（明确"像我"和"像别人"的边界）

**最低要求**：current_line/ 至少10张 + detail_views/ 至少5张。低于此数量品牌语法置信度标LOW。

## DNA 卡规范

每张有参考价值的图片对应一张 DNA 卡（YAML 格式），存放在 `.claude/knowledge/素材索引/` 下。

### DNA 卡模板
使用 `templates/素材DNA卡模板.yaml`

### DNA 卡的生成方式
1. **AI 初版生成**：系统读取图片，自动填写 DNA 卡各字段
2. **人工校对**：用户检查关键字段（problem_solved、form_response、transferable_technique），修正不准确的判断
3. **入库**：校对通过的 DNA 卡存入 `.claude/knowledge/素材索引/{品类}/` 目录

### DNA 卡的必填字段 vs 选填字段
**必填**（没有这些字段的 DNA 卡视为无效）：
- image_id
- source
- category
- silhouette
- hero_feature
- problem_solved
- form_response

**选填**（有了更好，没有不阻断）：
- brand, product, award
- block_relation, parting_strategy
- transferable_technique, transfer_constraint
- cmf, design_level, design_level_rationale

## 索引与检索规则

### 检索维度（Step 04/05 用这些维度搜索素材库）

系统在 Step 04 和 Step 05 需要检索素材时，按以下维度匹配：

1. **按"解决了什么问题"检索**（最高优先级，对应 B=60%）
   - 查询：用户痛点关键词 → 匹配 DNA 卡的 `problem_solved` 字段
   - 示例：查询"安装太重" → 匹配所有 problem_solved 包含"重量/轻量化/便携/单人安装"的素材

2. **按造型语言检索**
   - 查询：造型策略关键词 → 匹配 `silhouette` + `hero_feature` 字段
   - 示例：查询"极薄" → 匹配所有 silhouette 包含"扁平/薄/低矮"的素材

3. **按品类检索**
   - 查询：品类名 → 匹配 `category` 字段
   - 用于同品类对标和跨品类灵感

4. **按设计水平检索**
   - 查询：设计水平范围 → 匹配 `design_level` 字段
   - 用于控制参照的水平区间（不要太低没学习价值，不要太高客户接受不了）

5. **按可迁移手法检索**
   - 查询：设计手法关键词 → 匹配 `transferable_technique` 字段
   - 示例：查询"隐藏散热" → 匹配所有 transferable_technique 涉及散热隐藏的素材

### 检索结果排序
1. problem_solved 匹配度最高的排前面
2. 同等匹配度下，design_level 3-4 分的优先（可迁移的最佳区间）
3. 有奖项的优先于无奖项的
4. 有 transferable_technique 的优先于没有的

## 素材库规模要求

### 最低可用阈值
- 主品类（如灯具）：≥50 张有效 DNA 卡
- 跨品类：≥20 张有效 DNA 卡
- 低于阈值时，系统在 Step 04 提示"素材库覆盖不足，建议补充 {缺失品类} 的素材"

### 建议目标
- 主品类：200-300 张
- 跨品类：50-100 张
- 覆盖至少 5 个不同品类的跨品类参照

### 跨品类冷启动包（必建，解决路径B失效问题）

路径B（视觉驱动发现）需要品类多样的图片。如果素材库80%以上是同一品类，路径B等于废的。
必须优先建立一个小而强的跨品类冷启动包：

| 品类 | 数量 | 重点关注 |
|------|------|----------|
| 消费电子（手机/笔记本/耳机） | 8张 | 极致薄、一体化、精密工艺 |
| 汽车内外饰 | 8张 | 曲面张力、贯穿式设计、CMF对比 |
| 医疗设备 | 8张 | 便携化、人机交互、清洁感 |
| 户外装备 | 8张 | 轻量化、模块化、耐用感 |
| 家电 | 8张 | 操作直觉、材质混搭、功能可见性 |
| 家具 | 8张 | 比例、结构表达、材质温度 |
| 运动装备 | 8张 | 人体贴合、动态张力、减重 |
| 工具类产品 | 8张 | 握感、力量传达、耐用 |
| 建筑构件 | 8张 | 模数化、隐藏五金、极简线条 |
| 高端包装/香水/美妆 | 8张 | 精致感、开合仪式感、材质高级感 |

**总计80张**。每张必须有图、有DNA卡、有至少1个extractable_detail。
不需要一次做到很深，但必须覆盖品类多样性。

## 素材库维护规则

1. **新项目结束后**：将项目中发现的优秀竞品/参照图入库
2. **年度更新**：每年补充当年 Red Dot / iF 获奖作品
3. **淘汰机制**：连续 5 个项目未被检索到的素材，标记为"低活跃"，不删除但降低检索权重
4. **品类扩展**：进入新品类时，优先爬取该品类 Top 10 品牌的代表产品

## 与现有知识库的关系

- **灯具设计大师库**（`knowledge/灯具设计大师库.md`）：提供品类内的坐标体系和标杆定义，是"评价基准"
- **视觉素材库**：提供具体的视觉参照图和可迁移手法，是"灵感来源"
- 两者配合：大师库告诉系统"什么水平算好"，素材库告诉系统"好的设计长什么样"
