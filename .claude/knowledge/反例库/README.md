# 反例库

反例库对系统稳定性比灵感库更重要。知道什么不能做，比知道什么能做更有价值。

## 反例类型

| 类型 | 含义 | 示例 |
|------|------|------|
| 学了就廉价 | 迁移后让产品显得cheap | 消费级塑料圆角用在工业灯具上 |
| 学了就不像品牌 | 违反客户品牌DNA | 把Dyson的极简白用在RAB的粗犷工业灯上 |
| 学了就超成本 | 工艺/材料超出BOM走廊 | 用整块CNC铝削出一体壳（适合Apple不适合OEM灯具） |
| 学了就难制造 | 现有供应链做不了 | 双曲面玻璃+隐藏LED（没有模具能力） |
| 学了就撞脸 | 太像某个标志性产品 | 灯具做成iPhone的倒角语言，一看就像在抄苹果 |

## 反例卡格式

```yaml
anti_id: "ANTI-001"
source_product: "某具体产品或设计手法"
what_not_to_do: "不能做什么"
why_dangerous: "为什么危险"
applies_to: "对什么品类/客户有效"
```

## 使用
- Step 04：每条造型策略应输出至少1张反例卡（反例库为空时，基于Step 02常见失败造型+品牌禁止码生成临时反例卡）
- Step 05：概念评审时检查是否触犯反例
- 反例库随项目积累：每次项目中发现的"踩坑"自动入库（Step 10自动执行）
