# 渲染提示词模板

## 模式A：参考图+差异描述（首选模式）

适用于：有素材库参考图或Step 08粗渲染通过的图时。
将参考图和以下文字一起发给渲染AI（GPT-4o / Gemini / Nano Banana）。

```
=== 渲染参考图 ===
[附上参考图]

=== 基于参考图的修改指令 ===

保留不变的（参考图中这些元素必须原样保留）：
1. [从F16锁定清单提取]
2. [如"整体扁平长条的比例关系"]
3. [如"正面中央的线性出光开口"]

需要修改的（和参考图相比，做以下调整）：
1. [具体修改项+修改后的样子]
2. [具体修改项+修改后的样子]
3. [具体修改项+修改后的样子]

材质与表面（覆盖参考图的材质）：
- 主体：[材料+表面处理+触感]
- 特征面：[材料+效果]
- 细节件：[材料+处理]

构图与渲染设置：
- 角度：[如"3/4俯视角度，约45度"]
- 背景：[主视角=白色/浅灰 或 场景图=具体环境描述]
- 光线：[主光+补光描述]
- 风格：[如"professional product photography, studio lighting"]

绝对禁止（不能出现的元素）：
1. [从Step 08的drift_items提取]
2. [品牌红线禁止项]
3. [如"No decorative surface texture"]
4. [如"No visible screws or fasteners"]
```

## 模式B：纯文字创意总监brief（备选模式）

适用于：没有合适参考图，或用户明确要求纯文字生成时。

### 主视角提示词

```
[产品类型] professional product photography.

Product: [3句话视觉描述。第1句=整体形态+比例。第2句=Hero Feature占50%篇幅。第3句=材质感觉]

Scale: [参照物尺寸感，如"长度约等于一个笔记本电脑"]

Material & Surface: [具体材料+表面处理+触感]

Composition: [角度, 焦段, 景深]

Lighting: [主光+补光+环境光]

Background: clean white/light gray studio backdrop, subtle reflection on surface

Style: professional product photography, studio lighting, commercial quality, sharp focus throughout

=== CRITICAL: Must preserve ===
1. [Hero Feature的具体几何描述]
2. [体块关系的具体比例]
3. [F16锁定清单的关键项]

=== CRITICAL: Must NOT appear ===
1. [Step 08.5漂移项]
2. [品牌红线禁止项]
3. [至少4条具体几何禁止约束]
```

### 场景图提示词

```
[产品类型] in its natural environment.

Product: [同上3句话视觉描述]

Scene: [具体使用场景，包含环境、人物活动、光线条件、时间]

Composition: [角度, 焦段, 适度景深]

Lighting: [场景自然光线描述]

Mood: [场景氛围关键词]

Style: lifestyle product photography, natural lighting, editorial quality

=== CRITICAL: Must preserve ===
1. [Hero Feature]
2. [产品整体比例]
3. [材质感]

=== CRITICAL: Must NOT appear ===
1. [禁止元素]
```

## 粗渲染提示词模板（Step 08 粗渲染阶段使用）

快速出图用，关注造型大方向，不关注材质细节。

### 模式A（有参考图时）：
```
基于这张参考图，做以下修改：
[用2-3句话描述和参考图的关键差异]
产品类型：[品类名]
白色背景，3/4视角，产品摄影风格。
禁止：[3条核心禁止项]
```

### 模式B（无参考图时）：
```
[产品类型]的产品概念渲染。
整体形态：[轮廓描述，2句话]。
最醒目特征：[hero_feature]。
白色背景，3/4视角，产品摄影风格。
禁止：[3条核心禁止项]
```

## 防漂移检查清单（用户出图后自查）

每次出图后，对照以下清单检查：
- [ ] Hero Feature是否是画面中最醒目的元素？
- [ ] 整体比例是否和Step 08第3步描述一致？
- [ ] 有没有出现禁止项中列出的元素？
- [ ] 材质和CMF方向是否和Step 08第6步一致？
- [ ] AI有没有自行添加概念定义中没有的装饰/纹理/结构？
- [ ] 产品看起来像是可以量产的真实产品，还是CG概念图？
