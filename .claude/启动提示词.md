# 工业设计系统启动提示词

## 使用方法
复制下方任一提示词，粘贴到 Claude Code 对话框中即可启动。

---

## 提示词1：完整项目（有客户）

```
启动工业设计工作流。

品类：[填品类，如 LED Grow Light]
客户：[填客户名，如 Agrolux]
目标市场：[填市场，如 北美]
价格带：[填FOB区间，如 $60-85]

按 CLAUDE.md 的 V4.3.1 流程执行。从 Step 00 开始，每步跑完输出结论，等我说"继续"再跑下一步。Step 01-02 可以一口气跑完不用等我。
```

---

## 提示词2：完整项目（只有品类，没有客户）

```
启动工业设计工作流，品类优先模式（M1a / Standard变体）。

品类：[填品类]
目标市场：[填市场]
价格带：[填FOB区间]

先跑品类扫描和设计全景学习，Step 03 再匹配客户。
```

---

## 提示词3：快速模式（品类已学习过）

```
启动工业设计工作流，快速模式（M2 / Fast）。

品类：[填品类]
客户：[填客户名]

品类谱系图已存在，跳过 Step 01-02，从 Step 03 开始。
```

---

## 提示词4：批量生成 DNA 卡

```
帮我批量生成视觉素材库的 DNA 卡。

素材库路径：~/Desktop/设计素材库/[填子目录，如 RedDot/2024/lighting]

逐张读图，按 .claude/templates/素材DNA卡模板.yaml 格式生成 DNA 卡，存到 .claude/knowledge/素材索引/ 对应品类文件夹。每生成5张暂停让我校对。
```

---

## 提示词5：继续上次项目

```
继续上次的工业设计项目。

客户：[填客户名]
上次停在：Step [填步骤号]

加载客户记忆，从上次停下的地方继续。
```
