## 你需要做什么

1. 先完整读一遍 CLAUDE.md，理解系统架构
2. 用户会用"启动提示词"告诉你要做什么项目
3. 按 CLAUDE.md 里的流程执行，每步跑完输出结论，等用户说"继续"
4. 用户在3个节点会介入：Step 03选方向、Step 05选概念、Step 08出图反馈
5. 用户反馈时，问一句"这是这个客户特殊还是通用的"，客户特殊的存客户文件，通用的改规则文件
6. Git 推送使用 `gh auth login` 认证，不要在文件中写入明文Token
