# research-pack — 搜索SOP

## 竞品矩阵搜索策略

**Step 1：广搜**
搜索词：`{品类关键词} site:amazon.com` + `{品类关键词} review` + `{品类关键词} best 2025`
目标：识别直接竞品品牌和型号列表

**Step 2：筛直接竞品**
直接竞品标准：
- 同品类（相同使用场景和功能集）
- 同价格带（±50%以内）
- 同目标渠道（Home Depot/Amazon/Walmart）
排除：母公司、合作伙伴、完全不同品类的产品

**Step 3：逐个抓参数**
每个竞品必须搜索：品牌+型号+价格+关键规格+主要卖点+用户差评关键词
搜索顺序：官方产品页→零售商详情页→说明书PDF→第三方评测

## 来源优先级

```
[H] 官方产品页、说明书PDF、认证数据库（FCC/UL）
[M] 零售商详情页、第三方评测、行业报告
[L] 论坛讨论、AI推测
```

每次搜索最多引用1条AI推测，且必须标注`[AI推测-L]`。

## 取证失败降级规则

1. 第一次失败→换2个备选来源（零售商页/说明书PDF/第三方店铺）
2. 备选仍失败→字段标`UNKNOWN`
3. 每个UNKNOWN字段必须附：最小验证动作（格式：`验证方式：[具体动作] | 预计耗时：10分钟内`）

## 市场断言证据分层

| 断言类型 | 最低证据要求 |
|---------|------------|
| "市场空白/几乎没有" | N≥5个SKU的完整列表（品牌+价格+关键参数） |
| "普遍/大多数竞品" | N≥3且覆盖主流渠道（Amazon+至少1个实体渠道） |
| 不满足以上 | 改写为"基于[N]个样本的有限观察"，禁止绝对表述 |

## 竞品对比表输出格式

```yaml
competitor_matrix:
  - brand: "NEBO"
    model: "Slyde King 500"
    price: "$19.99"
    key_specs:
      - "500流明[H]"
      - "磁吸底座[H]"
    differentiator: "四合一功能（手电/工作灯/磁吸/挂钩）[H]"
    user_pain: "电池仓盖容易松动[M]"
    source: "https://www.amazon.com/..."
```

## 用户评论高频关键词提取

搜索词：`{竞品型号} review problems` + `{竞品型号} complaints`
提取：1星和2星评论中出现≥3次的关键词
输出格式：`关键词 (N次提及)[M/L]`

## 新客户自动取证4个字段

当 `knowledge/clients/{client}.md` 不存在时，自动搜索：
1. 目标价格带（看竞品和历史产品定价）
2. 必须认证（按目标渠道和品类）
3. 风格禁忌（看现有产品线设计语言）
4. 主要渠道（搜索品牌名+零售渠道）
