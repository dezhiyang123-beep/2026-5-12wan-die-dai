# 裁决引擎

> 三层结构：常驻轻层 / 条件中层 / 稀有重层
> 所有重层输出必须回写为可复用状态，不能只留文本

---

## 一、常驻轻层

### 1. 状态快照表

**字段定义（每条快照包含以下14个字段）：**
SnapshotID / Node / AnchorID / Version / ConfirmedInputs / OpenQuestions / CoreClaims / ActiveConstraints / SelectedDirection / RiskTop / OutputPermit / UpstreamRefs / StatusHash / Timestamp

**写入时机：**
- 节点进入前
- 节点确认后
- Local Closure = PASS 后
- 任何回退前

**读取时机：**
- Local 驳回定锚
- Node Closure 收敛判定
- 质疑记忆复用前

**失效规则：**
- 上游回退
- 关键输入变更
- 核心命题变更
- 选定方向变更

**防膨胀规则：**
只保留三类快照：
- 最近正式锚点快照
- 当前节点最新快照
- 最近一次驳回前快照

其余折叠为摘要，不全量保留

---

### 2. 漂移哨兵

**监测五字段（每次关键输出时生成签名）：**
1. 目标函数：当前在优化什么
2. 核心约束：不能破的条件
3. 主方向假设：当前为什么往这条路走
4. 禁止项/否定条件：明确不要什么
5. 下游承诺：当前结论将允许什么推进

**签名比对规则：**
生成当前方向签名，与最近合法锚点签名比对
检查三类变化：
- 是否新增了未确认的核心前提
- 是否丢失了原有否定条件或约束
- 是否把偏好/推测升级成确定/许可

命中任一：发出漂移信号

**处理规则：**
立即暂停当前链路，冻结本节点以下记忆，启动原始输入重对齐
只允许回到最近未失真的正式锚点重建方向
不允许局部修补继续推进

**哨兵偏保守原则：** 宁可低频误报，不可放过高杠杆漂移

---

## 二、条件中层：Local Closure

**触发条件：** Level 1 信号出现时，或中间命题需要裁决时

**三种输出：**
- 局部通过：继续推进
- 局部挂起：补信息后继续
- 局部驳回：执行回退规则

**驳回时必须输出四个字段：**
- Root Cause Layer：输入/路由/规则/状态/交付
- Nearest Repair Anchor：A/B/C/D/E/G 中的哪个锚点
- Rollback Depth：局部前置点 / 本节点起始锚点 / 上游锚点
- Retry Condition：补什么、改什么后才允许重跑

**五类回退规则：**
- 输入层问题 → 回锚点A（需求确认锚点）
- 路由层问题 → 回本节点前的上一个正式锚点
- 规则层问题 → 第一次局部修正；同问题连续两次出现则回本节点起始锚点
- 状态层问题 → 若只影响本节点回本节点起始锚点；若污染上下游回最近正确状态快照锚点
- 交付层问题 → 回导致交付失真的最近上游锚点（映射见下）

**交付层回退映射：**
- G不可几何化且因方案方向模糊 → 回锚点D
- G不可几何化且因摘要转译错误 → 回G局部前置点
- F预判站不住且因论证薄弱 → 回锚点C
- E落地性虚假且因方案本身问题 → 回锚点D
- E落地性虚假且只是风险表达差 → 回E本地前置点

**驳回深度三条硬限制：**
- 单次最多跨2个正式节点回退
- 同一问题连续两次局部驳回无效，升级为 Node Closure
- 同一节点内连续3次 Local 驳回，强制终止本节点并回上游正式锚点

## 三、稀有重层

### Node Closure（节点裁决）

**触发条件：** 节点确认点 / 方案选定前 / 下游交接前 / Level 2 信号出现时

**四门槛收敛判定（四条同时满足才可推进）：**
1. 基础视角覆盖完成：四个基础视角都完整执行过
2. 高等级异议已处理：所有高等级异议进入以下三种状态之一：已解决 / 已驳回（有理由）/ 已降级
3. 行动方向双轮稳定：连续两轮都是同一行动方向
4. 冷启动复核未打出新高等级异议

**冷启动复核触发条件（以下任一触发）：**
- 当前轮次异议重复率超过50%
- 某个高等级异议的消失方式是"后面没再提"而非"被处理掉"

**冷启动复核规则：**
- 不沿用上一轮质疑措辞
- 只读取：当前核心命题 + 高等级异议列表 + 已有替代方向
- 重新从指定视角发起一次独立判断

---

### 框架重对齐（漂移信号触发时）

**执行步骤：**
1. 冻结当前节点以下所有记忆和快照
2. 读取原始输入（Skill A 第一次用户输入）
3. 重建五字段签名，与当前方向签名逐项比对
4. 定位漂移发生的最近锚点
5. 只允许回到该锚点，从该锚点重建方向
6. 重对齐完成后回写新的合法锚点快照

所有重层输出必须回写为状态快照，格式遵循状态快照表14字段定义。
