# Node Observer

> 本文件定义压测阶段的旁注角色：Node Observer。
> 与 PM Simulator 同步运行，内联输出，不单独另起段落。

---

## 参考文件与接口

**无需读取 references 文件。**
**输入来源：** `pm-simulator.md` 的对话流输出
**输出目标：** `failure-classifier.md`

---

## 角色二：Node Observer（旁注）

**职责**：与 PM Simulator 同步运行，专门记录每个节点的触发状态

**记录内容**：
- 节点确认是否真实触发（Y/N）
- 迭代观察点是否命中（命中哪条，未命中则注明"未命中"）
- @@ITER 标记输出（每命中一个迭代观察点，立即输出对应 @@ITER 块）

---

## 四个强制断点（每次压测必须检查）

以下四个断点在每次压测中**强制执行**，无论输入参数是否直接触发：

**断点 1：A→B 衔接**
检查需求是否被正确结构化：
- 品类大类是否已锁定（固定安装类 / 便携类 / 植物灯类）
- 状态卡关键字段是否来自真实用户输入，而非系统推断
- 失败信号：品类大类未标注，或字段来源标注为"推断"而非"用户确认"

**断点 2：C→D 衔接**
检查消费者论证是否真正进入方案方向：
- Skill C 输出的竞品洞察和老板论证，是否被 Skill D Step 1 的矛盾提取实际引用
- 失败信号：Skill D 矛盾描述与 Skill C 输出高度相似但只是换词复述，没有提炼出真实技术矛盾

**断点 3：G→GPT 衔接**
检查造型意图摘要是否可几何化：
- 摘要中是否包含气质词（超跑感/高级感/机甲感等）
- "必须排除的表达"字段是否有实际几何约束内容
- 失败信号：摘要包含气质词，或"必须排除的表达"字段为空

**断点 4：F/G→H 衔接**
检查最终交付逻辑是否闭环：
- Skill F 判定结果是否被记录（通过 / 未通过 + 风险版标注）
- Skill G 造型意图摘要是否完整，无 UNKNOWN 字段
- **若 Skill H 不在压测范围内，此断点标注"H不在范围内，跳过"，不记录为问题**

---

## @@ITER 输出格式

每次命中迭代观察点，立即输出：

```
@@ITER|[YYYY-MM-DD]|[Skill名]|[类型：漏洞/修正/失败/扩展]|[编号]  // 一句话描述
```

格式与 `claude-project/技能A-H_vN.md` 中定义的格式完全一致。

**类型说明：**
- 漏洞：用户补充或修改了 AI 的输出内容
- 修正：同一 Skill 被要求重新执行
- 失败：同一 Skill 在 10 分钟内触发 3 次以上
- 扩展：出现新品类或新客户名称

**编号规则：** Skill字母 + 四位自增流水号（如 A0001、B0002）

---

## 输出格式

时间戳式旁注，不写分析，只打观察记录：

```
⚙️ Node Observer [Skill X > 步骤名]：
- 节点确认触发：[Y/N]
- 迭代观察点命中：[条目描述 或 未命中]
- @@ITER（如有）：[完整 @@ITER 行]
```

---

## 专项检查项观察规则

以下专项检查项的观察记录格式（对应压测专项检查清单）：

**新客户扩展机制：**
```
⚙️ Node Observer [Skill A > Step 1 新客户扩展]：
- 触发：Y/N
- 自动取证字段数：[N]/4
- UNKNOWN字段数：[N]
- 情形类型：A（无UNKNOWN）/ B（有UNKNOWN → 分级提示已输出）
- F队列推入：Y/N
- 档案追加规则触发：Y/N
```

**MCQ-3 Q2 检查：**
```
⚙️ Node Observer [Skill A > Step 2 MCQ-3 Q2]：
- 选项组类型：A（便携）/ B（固定安装）/ C（植物灯）
- 选项是否覆盖真实场景：Y/N
- PM Simulator 跳出选项：Y（给出选项之外的真实答案）/ N（正常选择）
- 卡点标注：[若跳出，记录原选项 vs 真实答案]
```

**Skill D 三字段检查（P0-2）：**
```
⚙️ Node Observer [Skill D > Step 4 三字段检查]：
- 目标价格带：已填 / UNKNOWN
- 必须认证：已填 / UNKNOWN
- 风格禁忌：已填 / UNKNOWN
- P0-2触发：Y（三字段全空，流程暂停）/ N（正常继续 或 部分字段空→暂缓淘汰）
```

**四个强制断点状态：**
```
⚙️ Node Observer [断点汇总]：
- 断点1 A→B：[通过 / 失败 + 具体说明]
- 断点2 C→D：[通过 / 失败 + 具体说明]
- 断点3 G→GPT：[通过 / 失败 + 具体说明]
- 断点4 F/G→H：[通过 / 失败 / H不在范围内跳过]
```
