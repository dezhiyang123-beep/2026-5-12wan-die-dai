# 环境能力清单 v1.0

## 定位

结构化列出Claude Code在当前环境中可能具备的能力。每次审计启动前必须对本清单执行预检，确认哪些能力可用。

硬规则：
- 任何能力缺失结论必须有清单证据或探测证据
- 禁止"未检查先自我设限"
- 只有两种情况可以说"做不到"——能力清单明确没有，或已经做过探测并失败
- 不允许靠模型记忆自行判断能力边界
- 每次审计结束后，输出能力使用报告：哪些能力用了、哪些该用没用、有没有自我设限行为

---

## 能力清单

| 能力ID | 名称 | 类别 | 默认状态 | 预检方式 | 失败回退 |
|--------|------|------|----------|----------|----------|
| CAP-01 | 联网搜索 | 搜索 | 需预检确认 | 执行一次搜索查询，检查是否返回真实结果 | 标注UNKNOWN，给出具体搜索词和建议链接模板 |
| CAP-02 | 读取GitHub文件 | 读 | 需预检确认 | 读取一个已知存在的文件（如SKILL.md） | 报告文件不可达，记录错误信息 |
| CAP-03 | 写入/修改GitHub文件 | 写 | 需预检确认 | 在测试路径创建临时文件并删除 | 记录修改建议但不执行，提示用户手动操作 |
| CAP-04 | 读取本地文件 | 读 | 需预检确认 | 读取SKILL.md自身确认返回内容 | 报告环境异常，终止审计 |
| CAP-05 | 执行脚本/命令 | 执行 | 默认关闭 | 不预检 | 不使用 |

---

## 预检输出格式

```
【环境预检结果】
CAP-01 联网搜索：✅ 可用 / ❌ 不可用（探测结果：[描述]）/ ⚠️ 未确认
CAP-02 GitHub文件读取：✅ / ❌ / ⚠️
CAP-03 GitHub文件写入：✅ / ❌ / ⚠️
CAP-04 本地文件读取：✅ / ❌ / ⚠️
CAP-05 脚本执行：🚫 默认关闭

可用能力：[列表]
不可用能力：[列表 + 回退方案]
未确认能力：[列表 + 风险说明]
```

```
|------|----------|----------|------|

| CAP-02 | ✅ | 使用了X次 / 未使用 | |
| ... | | | |

自我设限检查：是否存在"能力可用但未使用"的情况？
- [具体描述，或"无"]
```
