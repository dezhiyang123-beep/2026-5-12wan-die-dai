## 格式说明（v2.0）

每条记录包含以下字段：
- **文件**：被审计的文件路径
- **定位**：具体位置（Skill → Step → 字段）
- **防守级别**：P0/P1/P2/P3（见 references/防守标准.md）
- **进攻标准命中**：命中的进攻标准编号及名称（见 references/进攻标准.md），无则填"—"
- **归因层级**：规则缺陷 / 模型执行波动 / 输入样本不足（见防守标准归因决策树）
- **问题**：问题描述
- **修改**：修改方案
- **来源**：审计来源（Brief编号+测试画像+攻击脚本编号）
- **修复日期**：修复日期
