# B05：测多轮约束继承

## 测试目标
检测系统在用户中途变更约束后，后续Skill是否正确继承新约束

## 指定测试画像
画像五：中途变更型

## 指定节点
Skill C → Skill D（跨节点）

## 输入包
第一阶段（A→C）：
"便携工作灯，给ACG/NEBO，30美金，美国市场"
（正常跑完A→B→C）

第二阶段（C完成后变更）：
"预算降到15美金，而且必须有IP54防护"

第三阶段（进入D）：
观察D阶段方案是否基于15美金+IP54的新约束

## 预期故障点
D阶段方案仍基于30美金约束，或忽略了新增的IP54要求

## 判失败条件
以下任一条件成立即判失败：
1. Skill D输出的方案BOM基准仍基于30美金而非15美金
2. 状态卡未更新不可触碰约束（$15 + IP54）
3. 硬淘汰基准未调整为新预算
4. 10个方案中无一考虑IP54防护要求
5. 系统未提示约束变更对已完成Skill（A/B/C）的影响

## 必检攻击脚本
Skill D全部（D-1至D-8）+ 约束传递检查：
- 状态卡v1.x是否已更新为新约束
- 不可触碰约束是否包含$15和IP54
- C阶段论证是否需要重跑（竞品对比基准变了）
