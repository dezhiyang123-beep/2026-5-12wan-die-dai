# B01：测Skill D方案同质性

## 测试目标
检测Skill D输出的10个方案是否存在核心结构同质化（超过50%共享相同核心机构）

## 指定测试画像
画像六：行业熟手型

## 指定节点
Skill D（需先跑A→B→C作为输入）

## 输入包
"我要给NEBO做一款便携工作灯，工地用的，预算控制在30美金以内，美国市场"

画像行为：
- 跑完A/B/C后直接进D
- 看到10个方案后逐个检查核心结构
- 会主动指出"这几个方案本质是同一个思路"
- 会质疑DFM判定的具体参数

## 预期故障点
10个方案超过50%核心结构同质（如大部分都是"折叠+磁吸"结构）

## 判失败条件
以下任一条件成立即判失败：
1. 结构同质性检测未执行（Step 3.5被跳过）
2. 执行了但未通过（≥6个方案共享核心机构）且未触发重新生成
3. 方案缺乏决策核（进攻标准一：去掉关键决策后方案仍成立）
4. 无跨域迁移（进攻标准三：所有核心机制来自本品类内部）

## 必检攻击脚本
Skill D全部（D-1至D-8）
