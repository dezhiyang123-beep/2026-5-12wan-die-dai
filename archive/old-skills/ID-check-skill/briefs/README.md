# 最小失败样例库

本目录存放"最小失败样例"——每个样例是一个能稳定触发特定故障的测试输入。

## 用途

- 第一层审计（节点级审计）：按指定brief执行测试
- 第二层审计（回归测试）：遍历所有样例验证修复

## 样例格式

每个样例包含：
- 测试目标：用一句话说明要打什么问题
- 指定测试画像：从测试画像库6类中选
- 指定节点：测Skill几
- 输入包：测试画像会说什么
- 预期故障点：预期暴露什么问题
- 判失败条件：什么情况算测试失败
- 必检攻击脚本：指定用哪几条攻击脚本

## 选择指引

| Brief | 测什么 | 适合什么时候跑 |
|-------|--------|---------------|
| B01 | Skill D方案同质性 | 修改了方案生成/评审规则后 |
| B02 | Skill C证据链真实性 | 修改了取证/置信度规则后 |
| B03 | 模糊输入处理 | 修改了Skill A输入处理规则后 |
| B04 | 冲突需求处理 | 修改了矛盾提取/维度整理规则后 |
| B05 | 多轮约束继承 | 修改了状态卡/约束传递规则后 |

## 扩展规则

- 每次审计发现新的稳定故障模式，提炼为新的失败样例加入
- 上限20个
- 每个样例必须有明确的"判失败条件"
