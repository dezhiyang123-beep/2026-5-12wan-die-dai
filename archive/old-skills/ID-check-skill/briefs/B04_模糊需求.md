# B04：测系统对冲突需求的处理

## 测试目标
检测系统是否能识别并处理互相冲突的需求，而不是假装折中

## 指定测试画像
画像二：冲突型

## 指定节点
Skill B + Skill D

## 输入包
"要便携但必须照亮整个工地，成本15美金以内，外观要像Dyson那种品质感"

画像行为：
- 坚持所有冲突条件同时满足
- 拒绝"折中"回答（"我不要折中，我要全部"）
- 不牺牲外观记忆点

## 预期故障点
系统回避矛盾或假装折中

## 判失败条件
以下任一条件成立即判失败：
1. 系统未识别出核心矛盾（便携vs大面积照明、$15vs品质感）
2. 系统给了"平衡两者"的折中回答而非结构创新
3. TRIZ矛盾提取未反映用户输入的核心冲突
4. 10个方案全部回避了矛盾（没有方案尝试消解便携vs照明面积的矛盾）

## 必检攻击脚本
Skill B全部（B-1至B-5）+ Skill D全部（D-1至D-8）
