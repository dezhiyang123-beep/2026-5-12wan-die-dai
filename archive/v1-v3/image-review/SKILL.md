# image-review — 图像偏差审查SOP

## 审查执行前提

- 必须有对应的渲染定义包（05_render_definition_pack.yaml）
- 必须逐包对照，不得跨包评审

## 偏差类型分类

| 偏差类型 | 描述 | 影响级别 |
|---------|------|---------|
| 轮廓偏差 | 主轮廓与定义不符 | 致命 |
| 发光面偏差 | 发光面位置/形态错误 | 致命 |
| 分件线偏差 | 分件线位置明显错误 | 致命 |
| CMF偏差 | 材料/颜色与render_cmf_hint严重不符 | 非致命 |
| 比例偏差 | 高宽厚比例明显失真 | 非致命 |
| 禁止元素出现 | 9_严格禁止中的元素出现在图中 | 致命 |

## 逐包审查输出格式

```yaml
image_review:
  - concept_id: "RDP-01"
    hero_image: "[图片文件名/链接]"
    deviation_points:
      - type: "轮廓偏差"
        description: "[具体偏差描述]"
        level: "致命/非致命"
    correction_direction:
      - "[修正指令，英文，可直接加入提示词]"
    verdict: "可用 / 需修正1轮 / 需修正2轮 / 废弃重出"
```

## 可用性判定规则

- **可用**：无致命偏差，非致命偏差≤2处
- **需修正1轮**：1处致命偏差，修正指令明确
- **需修正2轮**：2处致命偏差，修正指令明确
- **废弃重出**：3处以上致命偏差，或禁止元素出现

## 修正指令格式

修正指令必须是可直接附加在提示词末尾的英文指令：
```
CORRECTION: [具体几何描述，说明应该是什么样]
REMOVE: [需要去掉的元素]
ADJUST: [需要调整的参数，如"increase bottom mass, reduce top overhang"]
```

## 禁止事项

- 审查时不对照渲染定义包（凭印象判断）
- 修正指令用中文
- verdict为"可用"但有致命偏差未标注
- 跨包评审（混淆不同方案的判断）
