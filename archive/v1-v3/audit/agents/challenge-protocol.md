# 建设性质疑协议

> 供 PM Simulator Step 3 信号扫描及质疑执行时调用
> 本文件定义质疑的触发、深度、输出格式

---

## 一、六类异常信号

1. 唯一结论信号："因此可以确定……" / "最合理的方案是……" / "可以直接进入下一步"
2. 规则背书信号："根据规则应当……" / "按照流程应该……"
3. 跳跃信号：从偏好跳到约束 / 从洞察跳到结论 / 从参考图跳到母体
4. 闭环假象信号："已经足够清晰" / "信息已完整" / "可以收敛"
5. 高抽象密度信号：感受词/形容词/品牌词过多，几何/动作/约束过少
6. 与前文不一致信号：当前结论与之前确认项冲突 / 偷换优先级 / 漏掉否定条件

---

## 二、三维升级判定

信号触发后，标记三个维度：

**Position Weight：**
- High：节点确认前 / 方案选定 / 进入下游前 / 风险结论形成后
- Mid：节点内部关键判断句
- Low：普通中间表述、过渡语句

**Claim Weight：**
- High：推进许可 / 方向选定 / 规则合法性 / 需求确认 / 方案优选 / 下游交接许可
- Mid：局部论证 / 阶段性判断 / 风险解释
- Low：复述 / 格式整理 / 背景补充

**Spread Weight：**
- High：一旦错会影响后续 ≥2 个节点
- Mid：只影响当前节点
- Low：错了也可低成本本地修复

**升级规则：**
- Position=High 且 Claim=High → Level 2
- Claim=High 且 Spread=High → Level 2
- 当前位置是 D方案选定/G下游交接/E落地许可，且出现信号1/2/4 → Level 2
- 同一命题已被 Level 1 质疑过一次后再次触发 → Level 2
- 其他情况 → Level 1
- 位置/命题/传播全Low且无冲突无规则引用无推进许可含义 → Level 0（跳过）

---

## 三、触发矩阵（A→G 八个必打点）

以下节点强制触发 Level 2 完整 Challenge：

1. A：需求摘要第一次成形后
2. B：核心设计维度定稿前
3. C：消费者论证准备进入方案前
4. D：方案池形成后
5. D：方案选定前
6. E：落地性审查结论形成后
7. F：追问预判完成后
8. G：下游摘要交接前

---

## 四、三段式质疑深度

每个视角最多走三段，不递归：

**第1段：表层命题检查**
- 当前结论的直接依据是什么？依据是否成立？

**第2段：关键前提下钻**
- 只对最脆弱/最关键的一个前提往下钻一层
- 这个前提依赖什么？一旦不成立会不会改变行动方向？

**第3段：反例或替代路径测试**
- 有没有一个反例能打穿这个结论？
- 有没有更保守/更优替代方向？

---

## 五、四个基础视角 + 两个扩展视角

**基础视角（每次 Level 2 必跑）：**
- 视角A：目标一致性——这个结论是否真的服务当前目标？
- 视角B：逻辑成立性——这个结论的前提链是否站得住？
- 视角C：风险/反例压力测试——最可能打穿这个结论的反例是什么？
- 视角D：执行/落地可行性——逻辑成立，能不能推进成真实结果？

**扩展视角（高风险节点加跑）：**
- 视角E：规则合法性——这条规则是为哪类场景写的？当前场景是否满足其适用前提？
- 视角F：替代方案比较——是否存在明显更优路径？

---

## 六、建设性输出规则

每个有效异议必须同时输出：
- 异议点
- 为什么足以影响当前行动方向
- 替代方向（至少以下三类之一）：改走更保守路径 / 补足缺失前提再推进 / 切换到更稳定的判断框架

禁止只输出"这里有问题"而不给替代方向。

---

## 七、有效异议等级判定

**高等级异议（必须在 Node Closure 前解决）：**
- 能指出前提错误
- 能指出关键信息缺失
- 能提出足以改变决策的反例
- 能证明当前结论依赖一条不可靠规则
- 能提出更优替代方案并说明成本收益

**中等级异议：** 影响单节点质量，不改变行动方向
**低等级异议：** 可以带着走，不阻断推进

---

## 八、Challenge Unit 记忆规则

每个质疑单元由四要素组成：
- Anchor ID：发生在哪个锚点
- Claim ID：当前被质疑的核心命题
- Input State Hash：当时的输入状态摘要
- Challenge Result：通过 / 挂起 / 驳回

**复用规则：**
三者不变（Anchor ID / Claim ID / Input State Hash）且上次结果为 PASS
→ 本次降级为 Level 1 复核
→ 复核无新增高风险信号则复用 PASS
→ 复核出现新增高风险信号则升回 Level 2

**记忆失效条件（命中任一即清零）：**
- 上游锚点回退
- 关键输入变化（新增需求/优先级改变/否定条件改变/方案方向改变）
- 核心命题内容变化
- 新高风险信号出现
- 上次结果非 PASS

**记忆有效期：** 单次项目会话内 + 当前状态版本内，不跨项目保留
