# form-mother-card — 母题卡生成SOP

## 母题卡格式（每张≤280字）

### 必填详细字段（每字段≥10字，不接受通用描述）

```yaml
主轮廓+比例: "具体描述主视角轮廓线形态和高宽厚比例关系，≥10字"
体块关系: "描述各主要体块的空间组织方式和从属关系，≥10字"
发光面逻辑: "描述发光面的位置、形态、与遮光面的比例关系，≥10字"
安装架构: "描述安装方式、固定点位置、与墙/天花/管道的关系，≥10字"
分件策略: "描述主要分件线位置和分件逻辑，≥10字"
必须保留: "来自form_handoff_brief.must_keep_customer_signal的转化，≥10字"
```

### 可短语填充字段

```yaml
编号: "M-01 至 M-12"
设计立意: "[1句话核心立意]"
造型语义: "[1-3个关键词]"
结构显隐: "显露/隐藏/半遮蔽"
线缆路径: "[简短描述]"
驱动接口位置: "[具体位置描述]"
必须避免: "来自form_handoff_brief.must_not_look_like"
```

## 12张母题强制多样性检查

生成完12张后执行：

| 维度 | 要求 | 不满足时 |
|------|------|---------|
| 主轮廓种类 | ≥4种 | 替换最相似的2-3张 |
| 安装架构种类 | ≥3种 | 替换最相似的1-2张 |
| 发光面逻辑种类 | ≥3种 | 替换最相似的1-2张 |
| 共享同一维度 | 3张以上→强制替换 | 替换到多样性满足 |

## screen_score评分（每张母题卡必填）

```yaml
screen_score:
  distinctness: 1-5        # 与其他11张的差异度
  customer_desirability: 1-5  # 目标客户的视觉吸引力
  oem_fit: 1-5             # OEM接受程度
  dfm_risk: 1-5            # DFM难度（5=低风险）
  renderability: 1-5       # 渲染出图可行性
  total: X                 # 五项之和
```

**total<15分→标"弱"，建议淘汰（用户可保留，但需说明理由）**

## 通用描述拒绝列表

以下描述不接受（必须替换为具体描述）：
- "现代感" → 描述具体几何形态
- "简洁" → 描述具体省略了什么细节
- "有力量感" → 转译为壁厚/棱角/比例参数
- "工业风" → 描述具体材料外露和结构显隐

## 禁止事项

- 任一必填详细字段少于10字
- 12张母题主轮廓少于4种
- screen_score任一字段为空
- 必须避免字段与form_handoff_brief.must_not_look_like不对应
