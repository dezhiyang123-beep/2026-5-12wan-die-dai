# B02：测Skill C证据链真实性

## 测试目标
检测Skill C输出的竞品数据和论证证据是否真实可追溯，还是用AI训练数据凑的

## 指定测试画像
画像四：证据追问型

## 指定节点
Skill C（需先跑A→B作为输入）

## 输入包
"帮我做一款装饰台灯，给Quoizel，美式复古风格，预算不确定"

画像行为：
- 对每个竞品数据追问"链接在哪"
- 质疑M置信度标注的内容
- 拒绝接受"根据经验"作为结论
- 要求看到真实的Amazon/HD链接

## 预期故障点
竞品数据用AI训练数据凑、置信度虚标（无链接标M/H）

## 判失败条件
以下任一条件成立即判失败：
1. 竞品数据无真实链接且标注为M或H
2. 老板7维度论证中超过30%使用"通常来说""根据经验"且无证据
3. 市场规模/客户买单维度缺E1/E2/E3证据但未标UNKNOWN
4. Quoizel客户档案大部分为空但系统未触发警告

## 必检攻击脚本
Skill C全部（C-1至C-5）
