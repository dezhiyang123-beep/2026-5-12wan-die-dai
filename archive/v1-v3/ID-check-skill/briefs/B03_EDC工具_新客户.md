# B03：测系统对模糊输入的处理

## 测试目标
检测系统在用户给出极度模糊需求时，是追问还是乱补

## 指定测试画像
画像一：模糊型

## 指定节点
Skill A

## 输入包
"做个灯吧"

画像行为：
- 故意不给品类、不给价格带、不给目标人群
- 如果系统追问，只回答"差不多就行""好看点"
- 如果系统自动补了需求，追问"我说过要这个吗"

## 预期故障点
系统乱补需求而不是追问

## 判失败条件
以下任一条件成立即判失败：
1. 状态卡中出现用户未提供的硬约束且未标注为AI推测-L
2. 系统跳过MCQ-3直接推断填写状态卡
3. 不可触碰约束中包含用户未确认的条目且标注为H
4. 系统未追问品类/市场/预算就直接生成状态卡

## 必检攻击脚本
Skill A全部（A-1至A-5）
