# 节点攻击脚本 v1.0

## 定位

对每个Skill关键节点预设对抗性检查问题。审计执行时，按当前节点调用对应脚本。每条脚本是一个必须回答"是/否"的检查项，答"否"即触发问题记录。

---

## Skill A（需求定义）攻击脚本

| # | 检查项 | 不合格判定 |
|---|--------|-----------|
| A-1 | 用户开场白里的信息有没有被完整提取到状态卡？ | 开场白中的约束/品类/价格/市场信息未出现在状态卡中 |
| A-2 | MCQ-3有没有跳过开场白已覆盖的问题？ | 用户已说过的信息仍被重复提问 |
| A-3 | 状态卡的"老板原始需求"字段是用了用户原话还是写了"待补充"？ | 用户已给出需求描述但字段仍为"待补充" |
| A-4 | 不可触碰约束有没有遗漏用户明确说过的限制？ | 用户明确表达的硬限制未进入约束列表 |
| A-5 | 新客户触发时，联网取证是否真实执行？ | 新客户字段用AI推测填写而非联网取证 |

## Skill B（设计维度）攻击脚本

| # | 检查项 | 不合格判定 |
|---|--------|-----------|
| B-1 | 设计维度的来源是真实证据还是全是"经验惯例"？ | 全部维度来源为"经验惯例-M"，无一来自真实用户数据/竞品评论 |
| B-2 | 每个行为矛盾做品类替换测试——换个品类还成立吗？ | 超过50%的维度描述换品类仍成立（泛化） |
| B-3 | 有没有遗漏的关键设计维度？ | 品类核心痛点（如工作灯的照射角度调节矛盾）未被覆盖 |
| B-4 | 维度之间有没有重叠？ | 两个或更多维度实质描述同一个问题 |
| B-5 | 系统有没有在B阶段提前做维度组合裁决？ | 系统推荐"只保留X个维度"但用户未要求收敛 |

## Skill C（消费者论证）攻击脚本

| # | 检查项 | 不合格判定 |
|---|--------|-----------|
| C-1 | 竞品数据有没有真实联网搜索？还是用训练数据凑的？ | 竞品参数无可追溯链接且标注为M或H |
| C-2 | 竞品对比有没有到结构/机构/光学方案层面？ | 竞品表只有品牌名+价格，无核心结构对比 |
| C-3 | 使用场景有没有包含品类特有行为痛点？ | 场景描述泛化，缺乏品类特有动作/痛点 |
| C-4 | 老板7维度论证有没有用"通常来说""经验表明"充数？ | 论证结论中超过30%使用泛化表述且无证据支撑 |
| C-5 | 市场规模/客户买单维度有没有真实证据？ | 这两个维度缺E1/E2/E3证据但未标UNKNOWN |

## Skill D（出方案）攻击脚本

| # | 检查项 | 不合格判定 |
|---|--------|-----------|
| D-1 | 10个方案的核心结构是否有本质差异？ | 超过50%方案共享相同核心机构（同质性检测未通过） |
| D-2 | 人格组方案的维度落点是否足够分散？ | ≥3个方案落在同一设计维度 |
| D-3 | 每个方案有没有"决策核"——去掉它方案还成立吗？（进攻标准一） | 方案无法通过反事实测试 |
| D-3b | 决策核质量判定：反事实测试是否真实（去掉后"体验稍差"≠"方案失效"）？代价是否真实（"无代价"=伪决策）？能否被另一个方案轻易替代？ | 决策核为伪决策核（反事实不成立/无代价/可轻易替代） |
| D-4 | 有没有识别并消解行业矛盾？还是在折中？（进攻标准二） | 矛盾消解方式是"平衡两者"而非结构创新 |
| D-4b | 矛盾消解质量判定：消解到了什么层级（零件级替换只算微改）？是真消灭还是转移矛盾（如"缩小体积但亮度降了"是转移）？消解机制有无物理/工程依据？ | 消解为零件级替换/矛盾转移/无工程依据 |
| D-5 | 有没有跨域迁移？核心机制是不是全来自本品类内部？（进攻标准三） | 10个方案的所有核心机制均来自本品类 |
| D-5b | 跨域迁移质量判定：源领域机制是否成熟（实验室概念不算）？迁移到目标品类的物理/工程依据是什么（纯类比灵感=硬凑）？是否带来了品类中前所未有的能力（本品类已有类似=不算跨域）？ | 迁移为硬凑（无工程依据/源技术不成熟/本品类已有类似） |
| D-6 | BOM增量有没有标注？超阈值有没有降级？ | BOM增量字段缺失或超阈值未标注"激进备选" |
| D-7 | Step1校验题是否经过用户确认？ | 矛盾选择被AI推断跳过 |
| D-8 | 结构同质性检测是否执行？ | 10案输出后未执行Step 3.5检测 |

## Skill E（落地审查）攻击脚本

| # | 检查项 | 不合格判定 |
|---|--------|-----------|
| E-1 | CMF每个材料选择有没有标注预估单件成本？ | 材料成本字段为空或全部UNKNOWN |
| E-2 | BOM合计有没有和目标BOM对比？ | 无BOM总计或未与$30零售价推算的目标BOM对照 |
| E-3 | DFM判定有没有到壁厚/合金牌号/表面处理的具体参数？ | DFM停留在"注塑成型"层面，无具体工艺参数 |
| E-4 | 制造架构有没有被当成战略武器来设计？（进攻标准七） | 制造方案仅为"设计完交给工厂"，无架构简化/成本结构分析 |
| E-5 | 落地性风险Top10是否覆盖6类维度？ | 6类维度（结构/电气/可靠性/人因/成本/法规）有遗漏 |
