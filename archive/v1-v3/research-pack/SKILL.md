# research-pack — 三圈层搜索SOP

## 三圈层搜索执行顺序

### 第一圈：直接竞品（≥5个SKU，必须完成才进第二圈）

搜索词：`{品类关键词} site:amazon.com` + `{品类关键词} review 2025` + `{品类关键词} best`

直接竞品标准：
- 同品类（相同使用场景和功能集）
- 同价格带（±50%以内）
- 同目标渠道（Home Depot / Amazon / Walmart）
- 排除：母公司、合作伙伴、不同品类产品

每个竞品必须搜索：品牌+型号+价格+关键规格+主要卖点+用户差评关键词
搜索顺序：官方产品页 → 零售商详情页 → 说明书PDF → 第三方评测

### 第二圈：中国OEM供应商（≥3个）

搜索词：`{品类关键词} OEM manufacturer site:alibaba.com` + `{品类关键词} factory China`
取：价格范围 / 最小起订量 / 常见规格参数 / 认证情况

### 第三圈：相邻品类（≥2个）

搜索词：`{相邻功能关键词} alternative` + `{相邻品类} comparison`
目的：识别跨界威胁（其他品类产品替代本品类）和创新机会

## 主动反证搜索（每圈结束后执行）

搜索词：`{竞品型号} problems` + `{竞品型号} complaints` + `{竞品型号} alternatives`
提取：1星2星评论高频关键词（≥3次提及），格式：`关键词 (N次)[M/L]`
记录：任何"品牌退出/产品停产/需求萎缩"信号

## 来源优先级

```
[H] 官方产品页、说明书PDF、认证数据库（FCC/UL/CE）
[M] 零售商详情页、第三方评测、行业报告
[L] 论坛讨论、AI推测
```

每次最多引用1条AI推测，必须标注 `[AI推测-L]`。

## 取证失败降级规则

1. 第一次失败→换2个备选来源
2. 备选仍失败→字段标 `UNKNOWN`
3. 每个UNKNOWN必须附：`验证方式：[具体动作] | 预计耗时：10分钟内`

## 市场断言证据分层

| 断言类型 | 最低证据要求 |
|---------|------------|
| "市场空白/几乎没有" | N≥5个SKU完整列表（品牌+价格+关键参数） |
| "普遍/大多数竞品" | N≥3且覆盖主流渠道（Amazon+至少1个实体渠道） |
| 不满足以上 | 改写为"基于[N]个样本的有限观察"，禁止绝对表述 |

## 竞品矩阵输出格式

```yaml
competitor_matrix:
  - brand: "NEBO"
    model: "Slyde King 500"
    price: "$19.99 [H]"
    key_specs:
      - "500流明 [H]"
      - "磁吸底座 [H]"
    differentiator: "四合一功能（手电/工作灯/磁吸/挂钩）[H]"
    user_pain: "电池仓盖容易松动 [M]"
    source: "https://www.amazon.com/..."
    circle: "first"
```

## 禁止事项

- 市场断言少于5个SKU支撑
- 把母公司或合作伙伴计入竞品
- 跨型号数据不降级直接迁移
- 搜索失败不标UNKNOWN（宁可空白）
