## SCAMPER

Skill D中三个方案的固定分配规则：
- Modify方案：改变现有产品的某个核心属性（尺寸/材质/形态/比例）
- Combine方案：把两种不相关的功能或产品合并
- Eliminate方案：去掉所有"理所当然"的部件，看剩下什么还能用

### Modify（改变/修改）
**触发问题：**
- 如果把这个产品缩小到极致会怎样？
- 如果把最贵的部件换成最便宜的材料，功能还在吗？
- 如果改变使用姿势（手持→挂载→头戴），形态会怎么变？

**输出要求：** 改变点必须具体说明改变了什么，改变后的用户体验有什么不同。

### Combine（组合）
**触发问题：**
- 这个产品和哪个完全不相关的日常物品放在一起会产生新功能？
- 什么功能是目标用户在同一场景下一定同时需要的？
- 哪两种材料的物理特性组合起来能解决当前最大的制造矛盾？

**输出要求：** 说明组合的两个元素分别是什么，组合后解决了什么问题，带来了什么新问题。

### Eliminate（消除）
**触发问题：**
- 如果去掉开关，用户还能用吗？（用什么代替？）
- 哪个部件是"行业惯例"但其实没有它更好？
- 如果只保留一个功能，这个产品变成什么？

**输出要求：** 说明消除了什么，消除后用户行为如何改变，为什么这是进步而不是残缺。

## TRIZ矛盾分析

### 使用时机
Skill D Step1，在生成方案之前提取产品的核心矛盾。

### 矛盾提取流程

**第一步：找改善参数**
你想改善什么？从以下选择：
重量 / 尺寸 / 速度 / 力量 / 稳定性 / 可靠性 / 亮度 / 续航 / 成本 / 可制造性 / 易用性 / 美观性

**第二步：找恶化参数**
改善上面那个参数，会导致什么变差？
（同样从上面的列表中选）

**第三步：输出矛盾陈述**
```
矛盾：要提升[改善参数]，但会导致[恶化参数]变差
例：要提升亮度，但会导致续航变差
例：要减小尺寸，但会导致散热变差
```

**第四步：矛盾解法方向**
针对每个矛盾，给出2个解法方向：
- 方向A：从材料/结构层面解
- 方向B：从用户行为/使用模式层面解

### 使用规则
- 矛盾必须引用状态卡中已确认的字段，不能凭空创造
- 先生成3个候选矛盾（A/B/C），用户或AI从中选定模式（Mode A聚焦1个 / Mode B并行保留）
- TRIZ组的2个方案对应选定矛盾的解法（Mode A：同1矛盾出2解法；Mode B：各矛盾各出解法按配额）

## MAD顺序链

### 使用时机
Skill D Step5，对Top4方案进行深度评审。

### 角色定义

**Proposer（已在Step3完成）**
生成方案的角色，此时已输出10个短案，不再重复。

**Critic（挑毛病）**
角色设定：工厂生产主管，只关心能不能做、成本对不对、风险在哪里。
不接受"用户体验不好"这类软性批评。只接受：
- 结构上做不到的
- 成本上算不过来的
- 认证上有风险的
- 供应链上找不到的

每个方案输出3个问题，必须具体到"哪个零件/哪道工序/哪项认证"。

**Editor（修问题）**
角色设定：有10年量产经验的资深设计师。
针对Critic的每个问题，给出最小修复动作：
- 修复必须可操作（"换一种固定方式"而不是"改善结构"）
- 修复不能改变方案的核心卖点
- 修复后必须重新给DFM判定（PASS/FAIL）

**Judge（裁决）**
角色设定：模拟老板，按7维度打分。
评分标准（每项10分）：
1. 使用场景清晰度：用户在什么时候用，画面感强不强
2. 目标人群明确度：谁会买，为什么他会买
3. 差异化成立度：和竞品相比，差异是真实的还是自嗨的
4. 制造可行性：工厂现在能不能做
5. 成本结构合理性：BOM估算在价格带内吗
6. 市场规模判断：这个需求有多少人有
7. 客户买单可能性：ACG/Quoizel会不会接这个

输出评分表+推荐排序+第1名推荐理由（1句话）。

### 执行规则
- 顺序不可打乱：必须Critic全部完成后Editor再开始，Editor全部完成后Judge再开始
- Critic不能说好话，只找问题
- Editor不能新增功能，只做最小修复
- Judge评分必须给数字，不能只给文字描述

## Six Thinking Hats（可选）

### 使用时机
**不强制每次使用。** 当出现以下情况时触发：
- 用户或AI对某个方案的评价出现明显分歧
- Critic和Editor对同一问题反复循环
- Judge评分某个维度极低（低于5分）需要深入分析

### 6顶帽子

| 颜色 | 关注点 | 用于 |
|------|--------|------|
| 白帽 | 事实和数据 | 我们有什么确定的信息？ |
| 红帽 | 情感和直觉 | 用户看到这个的第一反应是什么？ |
| 黑帽 | 批判和风险 | 最坏的情况是什么？ |
| 黄帽 | 乐观和价值 | 如果成功了，最大的收益是什么？ |
| 绿帽 | 创意和可能性 | 还有没有完全不同的解法？ |
| 蓝帽 | 流程和总结 | 讨论到这里，下一步做什么？ |

### 使用规则
- 每次只用相关的帽子，不需要全部6顶都过一遍
- 用于打破僵局，不用于常规流程
